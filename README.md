# herdr

My herdr setup, mirroring my [tmux setup](https://github.com/anwarahmed/tmux)
(tmux session → herdr workspace, window → tab, pane → pane)

https://github.com/herdrdev/herdr

Copy the contents of this repository to `~/.config/herdr`.
The following files can be ignored:

- `README.md`
- `.git`
- `.gitignore`

## ArchLinux / Omarchy

Install the following packages:

```shell
yay -S herdr
```
